
# ExpenseFlow

A modern personal finance tracker built with Next.js, Prisma, PostgreSQL (Neon), and Vercel.

## 🚀 Live Demo

https://expenseflow-a9lpfab5p-aether-industries.vercel.app

## 🛠 Tech Stack

- Next.js 16
- React 19
- TypeScript
- Prisma ORM
- PostgreSQL (Neon)
- Tailwind CSS
- Framer Motion
- Recharts
- JWT Authentication
- Vercel
